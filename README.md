# daymark

A calm, responsive to-do and productivity app for planning your day, organizing projects, and making time for focused work.

## Features

- Create, edit, complete, and delete tasks.
- Give tasks a due date, priority, description, and project.
- Browse tasks by day, upcoming schedule, completion status, or project.
- Search task titles, notes, and project names.
- See daily progress and your completed tasks for the week.
- Use the built-in 25-minute focus timer.
- Keep tasks and projects in your browser with local storage.
- Use the responsive layout on desktop and mobile.

## Run locally

This is a static web app and does not require a build step or package installation. Open `index.html` in a browser, or serve the project directory with a local static-file server.

## Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl+K` or `⌘K` | Open task search |
| `Ctrl+N` or `⌘N` | Add a task |
| `Esc` | Close the open dialog or mobile navigation |

## Data and privacy

Tasks, projects, and focus-session counts are saved in the browser's local storage on the current device. They are not synced to an account or shared between browsers. Clearing the browser's site data removes the saved information.

## Built with

- HTML
- CSS
- Vanilla JavaScript

Google Fonts are loaded from Google Fonts when an internet connection is available. The app itself has no third-party JavaScript dependencies.
